# VRChat 改模素材管理库 · Electron 版

管理 VRChat 改模素材（衣装 / 发型 / 配饰 / 功能组件 / 着色器 …）的本地工具。界面全中文，数据全部留在本机，不依赖任何服务器，也不上传任何数据。

**当前版本：v1.1。**

## v1.1 更新摘要

- **价格与统计整块移除**：侧栏合计、设置里的汇率页、购买价格字段、卡片价格丝带、详情页价格 chip、价格筛选与排序、导出与 CSV 的价格列全部删除；既有素材数据里的价格字段也做过一次清理。
- **卡片大小三档**：点网格按钮在 中 → 大 → 小 之间循环（也可在设置里选），每页数量随档位自动换算（小 34 / 中 24 / 大 15），工具栏不再有每页数量下拉。
- **动效**：卡片入场带一点回弹、悬停上浮更跟手，侧栏收放平滑过渡，翻页条淡入；工具栏新增刷新按钮（点下去转一圈）。系统开启「减少动态效果」时这些动画自动关闭。
- **更轻的刷新**：编辑一条素材只重画那一张卡，不再整页重排；保存后编辑弹窗自动关闭，底下开着的详情页同步更新标题与存储路径。
- **统一的改名流程**：编辑页保存与右键「重命名」走同一套逻辑 —— 先查重（与已有素材同名会被拒绝并说明和谁冲突），再改磁盘目录、同步存储路径、刷新卡片与详情页；改名期间保存按钮锁定，宿主 8 秒无应答也会放行保存。
- **修复**：卡片标签被压成一两个字（现在最多 3 枚、超出显示 +N）；页面内拖拽封面会改掉别的卡片封面；窗口最小宽度提到 1160，− □ × 与顶栏按钮不再被裁。

## 快速开始

```
双击 启动素材库_Electron版.bat
```

窗口标题为「VRChat 改模素材管理库 · v1.1」。宿主（文件读写 / 目录扫描 / 联网抓取 / 下载 / WebDAV / AI 流式转发）由 Electron 主进程随窗口启动，监听 `127.0.0.1:8788~8792`，**不需要任何外部程序**。

快捷键：**F5** 刷新 · **F11** 全屏 · **Esc** 退出全屏 · **Ctrl+Shift+I** 开发者工具 · **Ctrl+O** 打开数据目录。托盘菜单提供显示/隐藏、刷新、打开数据目录、打开素材库目录、**检查更新**、关于、退出。

## 数据在哪

数据本体在 `vrclib-data\`，与程序同目录；浏览器/WebView 侧只是缓存副本。备份、换机时拷贝这个目录即可。凭证类字段（站点 Cookie / AI Key / WebDAV 密码）加密后存在渲染层 IndexedDB，**不写进 `settings.json`，也永不随备份导出**。

素材库根目录可在「设置 → 本地库与整理」里指定；点「选择文件夹」走的是 Windows 原生对话框，直接返回绝对路径，不需要手填。

**右键菜单**：在素材卡片上点右键即可打开这条素材的操作菜单 —— 查看详情 / 编辑素材 / 重命名 / 设置分类（悬停二级菜单，当前分类打勾）/ 添加标签 / 设置支持角色 / 打开素材文件夹 / 打开商店页面 / 复制（标题、原标题、本地路径、商店链接）/ 加入喜欢 / 隐藏 / 导出为素材包 / 删除素材。支持 ↑↓ 选择、→ 展开二级、← 返回、Enter 执行、Esc 关闭；靠近屏幕边缘时会自动往回收。

**主题与毛玻璃**：主题五档 —— 暗色 / 亮色 / 樱粉马卡龙（粉 + 杏黄）/ 天际蓝（淡蓝 + 白）/ 跟随系统；顶栏月亮按钮循环切换。「毛玻璃」是独立开关（默认开）：顶栏、侧栏、弹窗、右键菜单半透明 + 背景模糊，页面底色换成同主题渐变；卡片只半透明不加模糊，避免几十张卡时掉帧。设置 → 外观里可关。

**素材包导入逐条确认**：导入 `.vrcpack` 的预览里，每个素材一行，可单独勾选；已有的条目还能单独选动作 —— 跳过 / 更新元数据 / 更新元数据 + 追加文件 / 新增一条。顶部三个单选项是批量套用。判重顺序为「同源素材 ID → 商品 ID → 标题」，行上会标出是按哪条判为已有的。

**拖图补封面**：把图片直接拖到某张卡片的缩略图上、或拖到素材详情页左侧的大图上，松手即设为该素材封面（悬停时出现虚线框和「设为封面」），会自动压缩、写进封面缓存并落一份 `<文件夹名>.png` 到素材文件夹；详情页开着时立刻换图。拖的不是图片时仍走导入流程。

## 信息获取的两种方式

| 方式 | 做法 | 隐私 | 默认 |
|---|---|---|---|
| **手动粘贴源码** | 粘贴商品页 HTML / JSON，本地离线解析 | 零外部请求 | ✅ 默认 |
| **内置宿主联网** | 由主进程内置宿主发起请求 | 只从本机发出 | 需在「设置 → 联网与宿主」选择 |

> BOOTH 最佳实践：打开 `https://booth.pm/ja/items/<商品ID>.json`，整页复制粘贴，识别率最高。

已购列表与下载直链需要登录态，推荐用 `scripts/vrc-library-bridge.user.js`：在你已登录的浏览器里导出 JSON，再从「设置 → 数据管理 → 从用户脚本导入」粘贴导入。

## 把素材发给别人：素材包

不需要双方同时在线，也不需要服务器或网盘账号。素材是低频、大件的东西——打包发过去更实在，微信 / 网盘 / U 盘都行。

**导出**：多选素材 → 批量工具条「导出素材包」→ 选保存位置。

| 选项 | 默认 | 说明 |
|---|---|---|
| 包含文件本体 | ✅ | 不勾就只导出清单和封面（几百 KB） |
| 包含封面 | ✅ | |
| 包含备注 | ❌ | 备注常写私下信息（作者、坑、从哪买的） |
| 包含购买价格 | ❌ | 你的购买记录 |

署名会显示在对方的导入预览里，也决定他那边解到哪个子目录（`_来自\<署名>\`）。

产物是**标准 zip**（扩展名 `.vrcpack`），对方没装本程序也能双击/7-Zip 直接解压：

```
素材/冬季厚毛衣套装/ふわもこニット.zip
素材/戚风衣装/model.fbx
素材/戚风衣装/textures/body.png
vrcpack.json
```

素材目录会**递归收全并保留子目录**，不会把 `textures/` 这种结构摊平。

**导入**：两种入口 —— **把 `.vrcpack` / `.zip` 直接拖进窗口**，或导入菜单 →「从素材包导入」→ 选包；都会先出预览再确认。

**拖进来的普通素材**：`.zip`（没有 vrcpack.json 的那种）、`.unitypackage`、`.rar` / `.7z`、`.fbx` / `.blend` / `.psd`、甚至整个文件夹，直接拖进窗口就会弹出「导入素材」预览：一行一个素材，可以改标题、选分类、勾选要导入的项，再选**复制（默认，不动原文件）**或**移动**放进 `素材库根/分类/标题/`。压缩包原样入库、不自动解压；同名的多个版本（`衣装_v1.2`、`衣装_v2`）会自动并成一条素材的多个版本；一起拖进来的图片会作为封面。菜单里的「从文件导入」是同一个入口。

- 拖拽时全窗口有覆盖提示；有弹窗开着时不响应拖入，避免打断正在编辑的素材；
- 拖进来的 `.vrcpack` 仍是素材包预览；普通 `.zip` 会先尝试按素材包读，读不出清单就转成「导入素材」预览，不会只丢一句「这不是素材包」；
- 按**商品 ID** 去重（没有 ID 才退回标题）；
- 冲突三选一：跳过已有（默认）/ 用包里的信息更新元数据 / 两条都留；
- 文件落到库内 `_来自\<署名>\<标题>\`，不打乱你原来的分类结构；
- 只有清单的包会变成「未下载」素材（信息都在，点详情能看到来自谁的清单）；
- 每个文件解包时校验大小与 CRC32，损坏会明确报错，不会留下半截文件。

**清单对比**：对方只导出清单（导出弹窗里点「只导清单（不打包文件）」）发给你，你走「导入」→「对比对方的清单（找出他没有的）」，或把清单包拖进窗口后在预览里点「找出他没有的素材」。

- 列出**你有、他清单里没有**的素材，可搜索、全选、只选该发的；
- **相似项会标黄**（「疑似他有 · 某标题 90%」）：标题很像但商品 ID 对不上，默认不勾，由你确认——解决两边起不同名字的漏判；
- 勾「隐藏疑似他有的」可只看确定要发的，导出时若混入疑似项会再提醒一次；
- 匹配按商品 ID → 标题 → 原标题（忽略空格大小写），本地改过标题也不会误判；
- 勾选后「导出选中项」直接复用打包流程，得到完整包发给他；
- **全程只读**，不会改动你的库。

## 检查更新（v1.1）

入口有两处：**设置 → 关于与帮助 → 程序更新**，或托盘菜单「检查更新」。

点按钮时联网一次，读 GitHub Releases 的 `latest`，把 `tag_name` 与当前版本比较：

- 有新版 → 弹窗列出更新说明 + 「前往下载」，用系统浏览器打开发布页；
- 已是最新 → 直接提示当前版本；
- 仓库没有 Release、被限流、断网 → 各自给出明确原因，不会静默失败。

程序**不会自动替换自己**。下载新压缩包解压覆盖到当前目录即可，`vrclib-data\` 与 `本地素材库\` 不受影响。

| 事项 | 说明 |
|---|---|
| 更新源 | 默认取仓库内置的 `owner/repo`，也可在设置页改（换仓库不用改代码） |
| 发版要求 | Release 的 tag 必须写成 `v4.3.3` 这种形式（前缀 `v` 会自动忽略） |
| 私有仓库 | Releases 接口需要认证，读不到；建议公开仓库，或手动下载 |

## 从源码运行

```bash
cd electron
npm install
```

然后回到上级目录双击 `启动素材库_Electron版.bat`，或：

```bash
./electron/node_modules/electron/dist/electron.exe .
```

两个常见坑：

- 本机若设了 `ELECTRON_RUN_AS_NODE=1`，Electron 会以纯 Node 模式启动、**不显示窗口**。启动脚本里已经清掉这个变量，手动命令行启动时自己 `unset` 一下。
- 入口 HTML 必须留在**仓库根目录**：页面按 `location` 推导 `vrclib-data` 的位置。

不入库的目录见 `.gitignore`：`vrclib-data/`（你的素材数据）、`本地素材库/`、`runtime/`（日志与归档）、`electron/node_modules/`、`.workbuddy/`。

## 调试与验证

```bash
cd electron
node build/probe-electron.mjs      # 页面状态 + 宿主地址 + 模块是否齐全（需带 --remote-debugging-port=9222 启动）
node build/test-host-apis.mjs      # 内置宿主 14 项接口回归
```

启动调试端口：

```bash
cd electron
env -u ELECTRON_RUN_AS_NODE ./node_modules/electron/dist/electron.exe . --remote-debugging-port=9222
```

注意：本机环境若带 `ELECTRON_RUN_AS_NODE=1`，Electron 会以纯 Node 模式启动、窗口不出现，必须先清掉。

更细的结构与改动记录见 `electron/README.md`。
